# Neva-Book Design Agents

Project-local design skills for the Neva-Book website and photobook editor.

## Skills

- `neva-ux-director` — flow, hierarchy, routing, editor structure.
- `neva-visual-taste` — public-site art direction and premium visual polish.
- `neva-interaction-design` — controls, drag/drop, sliders, crop/zoom, micro-interactions.

## External references studied

The local skills are original Neva-Book-specific instructions informed by:
- Impeccable — https://github.com/pbakaus/impeccable
- Taste Skill — https://github.com/Leonxlnx/taste-skill
- Emil Kowalski Skills — https://github.com/emilkowalski/skills

They are intentionally adapted rather than copied wholesale so project-specific product truth remains authoritative and the three roles do not compete with each other.

See root `AGENTS.md`, `PRODUCT.md`, and `DESIGN.md`.

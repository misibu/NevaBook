# Neva-Book — восстановление сайта (16.11.2026)

## Что найдено

- [Исходники](https://github.com/misibu/NevaBook)
- `web/` — основной Next.js сайт, конструктор `/create`, калькулятор `/calculator`
- `api/` — ASP.NET Core API, БД PostgreSQL, заказы
- `preview/` — независимая статическая тестовая версия без бэкенда

В документации проекта указан `neva-book.ru`, но это **настроечный адрес**, не доказательство работающего домена.
Проверки 16.11.2026 не подтвердили доступность ни `https://neva-book.ru`, ни `https://api.neva-book.ru/health`.

## Публикация тестовой версии

1. Слить ветку `feature/restore-preview-calculator-20261116` в `main`.
2. Открыть [Settings → Pages](https://github.com/misibu/NevaBook/settings/pages).
3. В поле **Build and deployment → Source** выбрать **GitHub Actions**.
4. Запустить workflow `Neva-Book preview (GitHub Pages)` через Actions → Run workflow, если автозапуск после слияния не произошёл.
5. Дождаться успешного deployment; после публикации ожидаемый адрес:
   `https://misibu.github.io/NevaBook/`
   До успешного deployment **не считать URL рабочим**.
6. Вкладки тестового стенда используют hash-маршруты: `#/calculator`, `#/create`, `#/books`.

## Границы тестовой версии

- Калькулятор: только примерные тарифы (база 1900 ₽; +90 ₽/разворот сверх 10; +450 ₽ за ткань; скидка 5% с 3 шт., 10% с 10 шт.).
- Эти цены **не являются офертой** и должны быть заменены утверждённым прайсом в `web/lib/pricing.ts` и `preview/app.js`.
- Конструктор: добавление изображений и раскладка 4 фото на демонстрационном развороте; фото остаются только в браузере.
- Публичный тестовый стенд **не принимает заказы**, не сохраняет проекты и не экспортирует производственные PDF.

## Для возвращения полноценного сайта

1. Проверить фактические приложения и логи в Amvera (из исходной архитектуры, но актуальный хостинг не подтверждён).
2. Развернуть `web/Dockerfile` отдельно от `api/Dockerfile`. Следовать требованиям используемого хостинга.
3. Настроить секреты БД, S3, домены, HTTPS и CORS **через окружение**, не коммитить реальные секреты.
4. Проверить `/health` у API и маршруты `/`, `/fotoknigi`, `/calculator`, `/create` у сайта.
5. Согласовать прайс, НДС/налоги, доставку, материалы и скидки.
6. Для приёма заказов потребуются серверная валидация цен, сохранение снимков/макетов и производственный экспорт PDF.

## Контрольная сборка

```bash
cd web && npm install && npm run typecheck && npm run build
cd ../api && dotnet restore && dotnet build -c Release
```

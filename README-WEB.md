# Neva-Book Web

New web platform scaffold. The existing Windows Neva-Book 1.1 source remains untouched.

- `web/` — Next.js + Builder.io visual pages + editor shell
- `api/` — ASP.NET Core API + PostgreSQL + S3
- `n8n/` — order notification starter workflow
- `docs/ARCHITECTURE.md` — deployment and next steps

The first supported book format is 20×20 cm. Production spreads are 406×206 mm before trim; the photo-cover template is 466×246 mm.
